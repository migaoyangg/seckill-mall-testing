## 项目一：秒杀商城后端测试自动化框架

**项目简介：** 基于 Spring Boot 的电商秒杀系统，包含用户、商品、管理员、订单、支付退款和秒杀模块，使用 MySQL、Redis、JWT、Lua、消息队列和乐观锁处理认证、库存和订单一致性问题。

**技术栈：** Java、Spring Boot 3、MyBatis-Plus、MySQL、Redis、JWT、RabbitMQ、JUnit 5、Mockito、MockMvc、pytest、requests、curl

**工作内容：**

- 梳理 Controller/Service/DTO 接口、参数校验、权限规则、业务码和订单状态机，设计正常、异常、边界、幂等和越权用例。
- 使用 JUnit 5、Mockito、MockMvc 编写 Service 与 Controller 自动化测试，覆盖用户、商品、管理员、订单、支付回调和秒杀库存核心分支。
- 使用 pytest + requests 编写真实接口自动化，利用 fixture 管理账号、Token、Session，使用参数化复用登录参数校验。
- 使用 curl 验证注册登录、JWT + Redis 鉴权、管理员权限、订单创建/取消/支付和重复请求场景，并通过 SQL/响应数据检查状态和库存变化。
- 根据失败日志定位并修复参数类型异常处理、管理员路径拦截配置和 Token fixture 复用导致的测试不稳定问题。
